# GitHub presentation — v0.1.0

## Public positioning

**The model reasons. The agent persists.**

Ginger Tail is a small, local-first Node.js runtime foundation for long-lived AI agents. It separates temporary model calls from persistent state, source-aware memory helpers, and host-controlled permissions.

This is a reusable engine foundation, **not** a production-ready autonomous agent or a general plug-and-play agent framework.

## What the first screen should prove

The [README](../../README.md) now opens with a reproducible, **fully synthetic** two-agent example:

- One shared runtime, two independent identities and local stores.
- Separate synthetic evidence sources.
- Cartographer receives host approval, gardener does not.
- The example runs offline without API keys or real accounts.

No fabricated terminal recording is used: the README shows a compact table describing the example's behavior.

Design principles:
- Quiet dark background and a single orange tail-like thread.
- Three clearly labeled responsibilities: temporary model thought, persistent engine state, trusted-host policy.
- A little character without pretending that the engine is a complete conscious or autonomous resident.
- Legible text and no real Ginger identity, credentials, or memory.
