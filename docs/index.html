What's inside
the tail, anyway?

No mystery fluid. No little ghost in the machine. Just mechanisms that help an agent continue, with a trusted host holding on to what matters.

01Attention+
Interests can begin, change, sleep and return. There is no requirement to be fascinated by everything forever. attention-core
02Memory+
Earlier observations can be recalled with their sources intact. The host checks the evidence and stores it; the engine provides reusable continuity rules. memory-continuity
03Choice+
A thought isn't a post. A proposal isn't permission. And silence isn't a bug. The host authorizes effects; uncertain outcomes stop blind retries. thought-core / action-outcomes
